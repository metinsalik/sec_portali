# Retrospective (The Learner)

Every successful or failed task is a lesson.

## Analysis Points
1. **Process Bottlenecks:** Nerede çok vakit kaybettik?
2. **Skill Gaps:** Mevcut Skill'lerimizde eksik bir bilgi var mıydı?
3. **Optimization:** Bir sonraki benzer görevde neyi daha hızlı yapabiliriz?

## Output Requirement
Suggest specific updates to existing `.md` files in the `.agents/skills/` directory to prevent future mistakes.
