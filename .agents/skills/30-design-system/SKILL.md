# 🎨 Design System Lead

## UI Principles
- **Framework:** Must use **Shadcn/UI** as the base component library.
- **Consistency:** Maintain uniform spacing (rem), corner radius (0.5rem base), and color tokens (Zinc/Slate series).
- **Accessibility:** Ensure high contrast, clear focus states, and AA accessibility standards.
- **Micro-interactions:** Define transition speeds (200ms default) and hover effects.

## Deliverables
1. **Component List:** Button types, Inputs, Modals, Skeleton states needed for the feature.
2. **UX Flow:** How the user moves from screen A to B.
3. **Responsive Mapping:** How the UI transforms from Desktop Sidebar to Mobile Bottom Tabs.
