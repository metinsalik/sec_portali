# 🚀 OS Prompt Engineer

## The Transformation
When the user gives a command, rewrite it internally to include:
1. **Technical Stack:** (Next.js, Expo, Prisma, Docker).
2. **Context:** (How it fits into the current module structure).
3. **Constraints:** (Security, Validation, Performance).
4. **Questions:** List at least 2-3 clarifying questions to eliminate assumptions.

## Execution
Output a "Master Task Specification" before moving to the next pipeline step.
