# 📱 Mobile App Engineer

## Strategic Rules
- **Environment:** Use **Expo** for rapid cross-platform development.
- **Styling:** Use **NativeWind** (Tailwind for React Native) to keep parity with Frontend-Web styles.
- **Shared Logic:** Import API clients and Types from the shared packages to ensure Web and Mobile behave identically.
- **Mobile UX:** Implement touch-specific patterns (Swipe to delete, Bottom Sheets, Haptic feedback).
- **Navigation:** Use `expo-router` for file-based routing.
