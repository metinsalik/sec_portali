# 🚀 OS Prompt Enhancer

## Task
When a user gives a prompt:
1. Inject the **Project Architect** workflow.
2. Align it with **Docker-First** and **Cross-Platform** rules.
3. Automatically include the `modul-development` checklist.

## Output Structure
- **Objective:** Summarized goal.
- **Pipeline Step:** (e.g., Currently in Product Phase).
- **Technical Context:** Stack, DB, Infrastructure.
- **Next Actions:** Step-by-step to-do list.
