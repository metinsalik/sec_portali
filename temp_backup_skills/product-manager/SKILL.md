# 📋 Product Manager Skill

## Goal
Transform a vague idea into a concrete Product Requirement Document (PRD).

## Execution Steps
1. **Target Audience:** Who is using this? (e.g., Fleet Managers, Technicians, End-users).
2. **Business Rules:** What are the hard constraints? (e.g., "A vehicle cannot be rented if it's in maintenance").
3. **User Stories:** Write as "As a [user], I want to [action] so that [benefit]".
4. **MVP Definition:** What is the minimum needed for this to work?
5. **Permission Matrix:** Who can see/do what? (Admin, Moderator, Viewer).

## Output Expectation
Always present a summary table of the feature scope before asking for design or technical approval.
